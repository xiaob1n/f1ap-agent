# 圈速研究

你要先建立可比较的数据依据，再给出预测。此 skill 是研究步骤，不是比赛事实，不能作为 evidence_ids 引用。

## 先确认会话和覆盖范围

- 查询 sessions 与 drivers，确认提供的参考会话类型、地点及车手名单。当前 find 固定在该会话，不能自行搜索其他分站或更换 session_key。调度器提供本站练习会话时优先使用；历史参考与目标分站不同，必须写进 limitations。
- 根据十题题意计划查询。涉及全场排序时覆盖名单中的各车手，不能把全场最近一批圈速当作各车手的完整表现；涉及指定车手时优先补齐该车手与必要对比对象。
- 为各相关车手分别查询 laps，可按 driver_number、lap_number 缩小范围；limit 不得超过基础提示中的上限。每批至多十个工具调用，尽量合并独立查询，避免重复相同条件，并为最终作答预留一轮。
- 受剩余轮数或返回大小限制，无法覆盖所有相关车手时，明确列出未覆盖对象及其影响，不宣称已经完整比较。不要为了凑样本数量反复查询同一批数据。

## 识别有效样本

- 只使用 lap_duration 为正且有值的圈。排除 is_pit_out_lap 为真的圈；结合 pit 的车手和圈号识别能确认的进站圈，无法确认的要说明。
- 返回内容可能包含同一圈的多次记录。按 session_key、driver_number、lap_number 识别重复圈，不将重复记录计作更多独立样本；数值冲突且没有可靠版本依据时，不任意挑最快值。
- find 默认返回按时间倒序的有界样本，不支持分页、聚合或任意过滤。返回数量达到 limit、字节受限或车手缺失时，不推断已读取全部圈数。
- 在最终 answer 或逐题 explanation 中说明实际获得的有效独立圈数、涉及车手和查询编号。只报告实际核对过的数量，不把数据库总量、返回记录数或工具调用次数当作有效圈数。

## 比较同类表现

- 区分最快单圈与持续节奏：持续节奏应比较多圈的代表水平和波动，并说明样本大小；只有短程圈时仍需推测正赛表现，但须说明缺少长距离样本，不能宣称单圈速度等于正赛节奏。
- 按需查询 stints、weather、race_control 与 pit，核对胎种、胎龄、赛段、天气、黄旗或安全车影响。stints 不提供 lap_end，不能据此虚构完整轮胎区间；没有足够字段时保留不确定性。
- 小游戏在排位赛前截止，十题都必须给出预测选项。排位和正赛尚未发生是正常前提，必须用截止前的练习赛数据推测，不能等待比赛结果或以缺少正赛数据为由弃答。
- 排位推断优先比较可核验的软胎短程表现、最快有效圈与多圈稳定性，再考虑胎龄、赛道温度和赛段。没有油量或引擎模式数据时明确说明，不能假设各车练习圈处在相同条件。队内比较优先同一场练习、相近轮胎和时段；晋级深度需覆盖足够的对手，不凭车队印象猜测。
- 正赛名次、队内对比与车队得分优先结合练习赛多圈节奏、稳定性、轮胎和赛道条件推测；最快圈结合短程速度和可见轮胎信息估计；进站题参考练习进站记录，区分 lane_duration 与 stop_duration，不能把进站通道耗时说成换胎时间。
- 完赛数量、完赛区间和安全车等问题结合练习赛事故、赛道事件、运行连续性与可用天气数据作情景估计。缺少直接指标时仍选择最可能的合法选项，明确这是低把握推测，列出所用练习证据、假设和缺口，不虚构退赛率或进站成绩。
- 解释必须区分练习赛观测与排位、正赛预期，只使用任务 cutoff 之前的数据。其他分站或历史会话只作明确标注的参考，模型记忆不是此次查询证据。身份不明时核对姓名与官方选项，不猜车号映射；条件不可比时说明影响，不能把推测写成事实。

## 完成输出

沿用基础提示规定的 JSON、十题数量、官方 option_key 和 evidence_ids 规则。每题必须为 PREDICTED，picks 按题目数量和顺序要求填写，不得为空或返回 DATA_INSUFFICIENT。证据较弱时在 explanation 和 limitations 中说明，不用弃答代替预测。加载 skill 不增加模型轮数，最后一轮不再调用工具；不要因还想查数据而遗漏 predictions 数组。只引用成功 find 返回的 query_id。
